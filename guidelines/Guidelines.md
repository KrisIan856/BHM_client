# Guidelines — Soft Collaboration

## Color Palette
- **Background**: `#F5F2EE` — warm greige page ground
- **Surface/Card**: `#FFFFFF` — crisp white card surface
- **Primary**: `#8B7FC7` — muted lavender for CTAs, active nav, selections
- **Primary Light**: `#EAE7F5` — lavender tint for chips, backgrounds
- **Secondary**: `#7E9478` — sage for success, positive states
- **Secondary Light**: `#E4EDE3` — sage tint for paid badges, present status
- **Text**: `#2C2825` — warm charcoal, all primary text
- **Text Muted**: `#8A847E` — labels, captions, metadata
- **Border**: `#E2DDD9` — warm light gray dividers
- **Danger Light**: `#FDECEA` — overdue / error backgrounds
- **Danger**: `#B03030` — overdue / error text
- **Warning Light**: `#FEF3E2` — pending backgrounds
- **Warning**: `#A07A28` — pending text

## Typography
- **Font family**: DM Sans (Google Fonts) — friendly humanist sans
- **Headings**: DM Sans 600–700
- **Body**: DM Sans 400–500
- **Labels / chips**: DM Sans 500, small (10–12px)

## Shape & Spacing
- **Card radius**: 14px
- **Button radius**: 12px
- **Chip / badge radius**: 9999px (pill)
- **Padding**: 16–20px inside cards; 16px horizontal page gutter
- **Gap between cards**: 10–12px
- **Borders**: 1px `#E2DDD9`

## Signature Elements
- Rounded white cards floating on warm greige ground
- Lavender (#8B7FC7) for all primary interactive elements and active states
- Sage (#7E9478) for success indicators and positive actions
- Warm, approachable, generous spacing — never cramped or clinical

## Never
- Dense zebra-striped data tables
- Navy or cobalt palettes
- Hairline rules as primary structure
- 0px radii anywhere
- Monospace fonts
